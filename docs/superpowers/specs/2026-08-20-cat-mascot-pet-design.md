# 博客桌面宠物型吉祥物设计规范 (Codex-style Blog Mascot Pet Spec)

- **创建日期**: 2026-08-20
- **目标组件**: 仿照 Codex 桌宠形态构建灵动可爱的博客陪伴型 2.5D 猫咪吉祥物
- **核心定位**: 页面感知待机、随机闲置互动、拖拽悬空物理、打字伴读联动、科技箴言互动与一键火箭回顶。

> **实现现状（阅读本文前请先看这段）**
> 本文是当时的**设计稿**，其中的文件清单已与实现不一致，实际落地的形态是：
> - `components/pet/` 只有 `CatPet.vue` 与 `CatAvatar.vue`；**没有** `CatBubble.vue`，
>   `lib/` 里也**没有** `catFortunes.js`。
> - 桌宠后来改成**无文字**：去掉了对话气泡、箴言与运势文案（交互改为单击回顶、长按抚摸、
>   拖拽改位置、右键或 `M` 切换音效、打字触发 bongo 反应），音效由 `lib/catAudio.js` 合成。
> - 精灵图已随仓库提交在 `frontend/src/assets/pet/`，属于构建产物级别的静态资源；
>   生成本地素材用的 `scripts/slice_pet_sprites.py` 依赖作者机器上的原始角色图，
>   不是构建链路的一部分，也不需要在新环境执行。

## 2. 状态机与行为流转 (Behavioral State Machine)

### 2.1 状态枚举 (States)
1. `PAGE_IDLE` (页面专属待机姿态)
2. `RANDOM_ACTION` (随机主动闲置动作：伸懒腰/洗脸抓痒/灵光一闪/扑蝴蝶等)
3. `TYPING` (键盘打字模式：Bongo Cat 敲键盘)
4. `DRAGGING` (拖拽悬空状态：拎后颈皮蹬腿)
5. `PETTING` (被抚摸/点击状态：爱心眯眯眼、呼噜声)
6. `SLEEPING` (深度睡眠状态：趴卧、Zzz 冒泡呼吸、微弱呼噜声)
7. `LAUNCHING` (火箭回顶状态：戴竹蜻蜓/飞行帽冲天而起)

### 2.2 路由与页面专属待机 (Route-Aware Idle Mapping)

| 路由/页面 | 专属道具与外观 | 专属动作表现 | 专属语录与气泡 |
| :--- | :--- | :--- | :--- |
| **首页 (`/`)** | 冒热气的小咖啡杯/清茶 | 坐在草编软垫上轻晃双脚，偶尔捧杯轻吹一口气，尾巴悠闲晃动 | “今天也要写出优雅的代码～”, “来杯热茶，看看最新文章吧” |
| **文章详情 (`/post/:slug`)** | 金丝小圆眼镜 + 翻开的魔法羊皮书 | 戴上小眼镜一本正经伴读，小爪握着羽毛笔不时记录，跟随阅读进度眨眼 | “正在与你一同研读…”, “这个设计思路很妙！” |
| **归档目录 (`/posts`)** | 放大镜 + 藏书卷轴 | 身边堆着几卷羊皮纸与古籍，拿着放大镜探头翻阅寻找文章 | “让我找找还有哪些未读笔记～”, “知识库整理中…” |
| **关于我们 (`/about`)** | 小绅士领结 + “Welcome”小牌牌 | 双手合十或挥爪迎宾，偶尔举起欢迎牌，耳朵兴奋抖动 | “你好呀！欢迎来到至知的数字花园 ✨” |
| **404 页面 (`not-found`)** | 疑惑小问号 + 地图指南针 | 歪着头四处张望，抓抓小耳朵，寻找迷失的路径 | “喵？这片知识领域尚未被开拓呢…” |

### 2.3 随机闲置动作池 (Random Behaviors Trigger)
- **触发机制**：处于 `PAGE_IDLE` 状态时，每间隔 18~35 秒随机摇号执行一次 4~6 秒的独立动作：
  1. `STRETCH` (伸懒腰)：前趴翘臀拉伸。
  2. `GROOM` (洗脸理毛)：前爪轻擦面颊与耳朵。
  3. `EUREKA` (灵光一闪)：头顶弹跳出小灯泡，快乐原地小跳。
  4. `LOOK_MOUSE` (好奇追光标)：眼睛与小脑袋紧随鼠标坐标。
  5. `POUNCE` (扑蝴蝶/小光点)：面前出现光蝶，小爪一扑。
- **休眠机制**：连续 60 秒无任何用户操作，平滑过渡至 `SLEEPING` 趴睡模式；一旦发生鼠标移动、按键或点击立即惊醒（轻抖耳朵睁眼）。

## 3. 交互系统与手感打磨 (Interactivity & Micro-Interactions)

1. **自由拖拽 (Draggable & Sticky Edge)**：
   - 鼠标或触控按住宠物任意位置即可自由拖动。
   - 拖拽瞬间进入 `DRAGGING` 姿态（小猫身体被“拎住后颈皮”悬空，四肢小幅度晃动）。
   - 松开后带有丝滑的物理弹簧抛物线吸附至屏幕安全边距，并记忆用户喜好的放置位置（持久化至 `localStorage`）。
2. **键盘联动 (Bongo Mode)**：
   - 全局捕获输入框/键盘按键事件（如在搜索框、快捷键或任意输入时），小猫瞬间拿出微型键盘，双爪交替敲击并伴随清脆的木质敲击音效。
3. **点击抚摸与签文系统**：
   - 单击桌宠：触发治愈音效，猫咪表情变为愉悦眯眼/腮红闪烁，头顶弹出动态气泡展示随机科技箴言或运势签文。
4. **一键回顶与伴读进度**：
   - 双击猫咪或点击气泡“回到顶部”：触发火箭/竹蜻蜓音效与飞升动画，页面平滑滚动至顶部后从上方降落回位。
   - 桌宠底部环绕极简阅读进度光环（随页面滚动实时展示百分比）。
5. **声音开关与无障碍**：
   - 气泡右上角提供轻量小喇叭静音/开启切换；完全遵循 `prefers-reduced-motion` 规范。

## 4. 视觉设计系统 (2.5D Layered Vector Aesthetic)

- **色彩与质感**：
  - 身体采用柔和温润的象牙白与暖杏色（`#FFFDF8` / `#F5EBE1`），点缀淡粉腮红（`#F7A8A0`）与琥珀金瞳孔（`#D97706`）。
  - 配件保持博客典雅的红木暖棕（`#8B2500`）、复古金（`#E8AD38`）和暗夜黑（`#1C1710`），与整站 Editorial 极简学术风完美契合。
- **骨骼动效层**：
  - 独立图层分级：阴影层 → 尾巴层 → 身体躯干 → 道具后层 → 头部(面部表情/眼睛/耳朵) → 道具前层 → 前爪层 → 气泡特效层。
  - 基于 CSS 变量驱动的弹性缓动曲线（Spring Easing）与 RequestAnimationFrame 平滑插值。

## 5. 验证与测试规范

1. 路由切换测试：验证在 Home、Post、Posts、About 等各页面中待机姿态与配件切换是否精准无缝。
2. 动作流转测试：验证随机动作、打字 Bongo 模式、拖拽悬空与休眠唤醒之间状态机无死锁。
3. 响应式与跨端测试：验证桌面端（鼠标轨迹、拖拽）与移动端（触摸、自适应视口尺寸）体验良好。
4. 编译与构建测试：`npm run build` 无告警无打包异常。
