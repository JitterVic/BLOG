# 首页封面滚轮翻页设计

## 目标

首页封面固定为三页：001 封面、002 最近更新、003 热点文章。滚轮向下时切到下一页，向上时切到上一页；到达首尾页后保持不动。

## 方案

沿用现有 `usePageFlip` 单例 composable 和 `.flip-track` 位移轨道。`currentPage` 只允许为 0、1、2，滚轮方向映射为 `+1` 或 `-1`，动画锁保证一次滚轮手势最多翻一页。键盘、触摸和封面锚点继续复用同一页码入口。

翻页模式不再按视口尺寸或系统动效偏好回退，所有尺寸都使用三页整屏布局。页面根节点锁定滚动，轨道通过 `translate3d` 切换整页；现有移动端内容样式继续负责压缩版面。

## 验证

执行前端生产构建，并用浏览器脚本验证桌面视口下滚轮向下两次得到第三页、向上一次回到第二页，同时确认页面滚动位置不发生自然滚动。
